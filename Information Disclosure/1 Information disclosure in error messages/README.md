# LAB 1 Information disclosure in error messages

## Tujuan lab:
mengetahui nomor versi dari framework
	
## Brief:
web ini menampilkan pesan error berlebihan tentang versi pihak ketiga framework.
	
## Analisa:
dibagian produk endpoint
web menampilkan pesan error berlebihan ketika menginput data yang salah, ketika harusnya menginput dengan integer dan diganti menjadi string, web server langsung menampilkan pesan error tidak perlu bahkan dengan versi frameworknya
